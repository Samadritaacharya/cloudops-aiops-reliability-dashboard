# CloudOps web design system

Dark editorial surfaces, restrained glass, oversized reliability typography, and motion that explains system state.

References: Taste Skill v2 for audit-first hierarchy; awesome-design-md for explicit design constraints; React Three Fiber for the system map; ShaderGradient for ambient motion; liquid-glass-js as visual reference only; liquid-logo as shader-concept reference only. The central orb uses original GLSL.

Rules: reduced-motion support, WebGL fallback, no remote font, no model key, no database, no analytics service, no paid API, and explicit synthetic-data behavior. Deploy `frontend/` as the Vercel Root Directory.
